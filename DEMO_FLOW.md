# Demo flow

Use the sidebar to start at **Command centre**. Select **Institutes & projects** and create a surprise inspection. The assignment control page makes each transition visible. Do not skip sealing: the backend rejects early reveal and repeat sealing.

For the evidence integrity demo, use the Evidence page, verify one file normally, then tamper and re-verify the same record. The original server hash remains in the row, and a `TAMPERED_EVIDENCE` alert plus `EVIDENCE_TAMPER_DETECTED` audit record are appended.

Use the Audit page to verify the chain after the tamper event. The attendance page distinguishes observed records from the inferred anomaly score. CCTV copy uses the exact boundary language: configured compatible streams/providers, not every camera.
